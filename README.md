Screenshots located in Screenshots folder.

**Project Overview** 

This project involves creating a modern Spring Framework back-end for a travel agency's vacation booking application. The goal is to replace a legacy back-end system with a minimally viable product (MVP) that integrates well with the Angular front-end provided by the agency. The new back-end leverages object-oriented principles, Spring Boot, and MySQL for scalability, maintainability, and performance.

**Features
Object-Oriented Design:**

Includes packages for controllers, services, DAO (Data Access Object), and entities to promote modularity and separation of concerns.
Implements object-oriented principles like encapsulation, abstraction, and design patterns for maintainable code.

**Relational Database Integration:**

Integrates with MySQL using Spring Data JPA.
Supports CRUD operations for managing vacation packages, customer orders, and excursions.
Validation:

**Validates user input using annotations to ensure data integrity.
REST API:**

Provides RESTful endpoints for the Angular front-end to fetch and post data.
Includes Cross-Origin Resource Sharing (CORS) support to allow communication between the front-end and back-end.
Sample Data:

**Preloads five sample customers and vacation packages into the database.
Order Management:**

Allows users to place orders for vacations and excursions, with orders stored in the database.
